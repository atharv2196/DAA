# Design and Analysis of Algorithms (DAA) Laboratory

This repository contains my C++ implementations for the Design and Analysis of Algorithms laboratory assignments. Each assignment demonstrates an algorithm or design technique applied to a practical problem.

## Assignments

| No. | Assignment | Main Topic | Description |
|:---:|---|---|---|
| 1 | Bank Transaction Sorting | Merge Sort | Sorts bank transaction records by transaction date using the divide-and-conquer approach. |
| 2 | Bank Transaction Sorting | Quick Sort | Sorts bank transaction records by transaction amount or date using partitioning. |
| 3 | Fractional Knapsack Problem | Greedy Algorithm | Maximizes the total value of divisible items within a given capacity. |
| 4 | Emergency Vehicle Shortest Path | Dijkstra's Algorithm | Finds the shortest travel-time route for an ambulance to reach a hospital. |
| 5 | Multistage Graph | Dynamic Programming | Determines the minimum-cost path through a multistage directed graph. |
| 6 | 0/1 Knapsack Problem | Dynamic Programming | Maximizes item value without exceeding the capacity when items cannot be divided. |
| 7 | University Timetable Scheduling | Graph Coloring | Assigns examination time slots while avoiding conflicts between courses. |
| 8 | Delivery Route Optimization | Least-Cost Branch and Bound | Finds a minimum-cost tour that visits each city once and returns to the starting city. |

## Algorithms at a Glance

- **Divide and Conquer:** Merge Sort and Quick Sort efficiently sort records.
- **Greedy Algorithm:** Fractional Knapsack maximizes value using the value-to-weight ratio.
- **Shortest Path:** Dijkstra's algorithm finds shortest paths in graphs with nonnegative edge weights.
- **Dynamic Programming:** Multistage Graph and 0/1 Knapsack solve optimization problems using smaller subproblems.
- **Graph Coloring:** Assigns non-conflicting examination time slots.
- **Branch and Bound:** Optimizes delivery routes by exploring promising solutions and pruning unpromising alternatives.
